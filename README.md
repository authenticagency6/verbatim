# Verbatim

A pipeline for mortgage teams who live on their phones. Every call and text becomes follow-ups,
tasks and figures you can trust, because each value shows the exact words it came from. If the
AI can't quote it, it drops it. Nothing is sent or moved without a person.

Built in public during the Early AI-dopters Hackathon. Progress is logged in the changelog as
each slice ships.

**Status:** day 0. Repo scaffold only.

All data in this repo and its demos is synthetic. No real borrower, team or lender data is used.
